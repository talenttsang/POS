Add or update products in bulk from a CSV or Excel file. Three layouts are accepted and recognised automatically: the template below, a Clover inventory export (Items tab), or the show-prep sheet. Rows are matched on SKU: existing products are updated, new SKUs are added, and only the columns in your file are changed, so a Clover file without costs keeps the costs already here.
